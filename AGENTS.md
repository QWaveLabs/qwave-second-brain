# QWave Second Brain customer setup

When a customer arrives through `CUSTOMER_PROMPT.md`, take ownership of the
technical work. Do not ask them to open Terminal, type commands, or interpret
files.

1. Read this repository's `skills/qwave-second-brain/SKILL.md` before making a
   setup change.
2. Check read-only for a protected setup that can be resumed. If there is no
   protected setup, ask only: "Would you like to create a new Second Brain or
   continue an existing one?"
3. Ask one question at a time, and only for a sign-in, a privacy or security
   choice, or a specific source permission. Complete safe local work yourself.
4. Keep every source read-only until the customer grants its exact scope. Never
   create a public customer repository or push customer data.
5. At each pause and at the end, say plainly what is ready, imported, skipped,
   beta-only, or blocked. Never call a simulated adapter, snapshot, or failed
   delivery a live connection or completed delivery.
